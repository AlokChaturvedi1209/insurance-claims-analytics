# Portfolio Summary

## Project Description

Built a reproducible synthetic insurance claims operations analytics workflow
that combines deterministic Python data generation, PostgreSQL modeling and
validation, operational SQL, and a three-page Power BI report. The project
focuses on backlog aging, stage SLA exposure, completed turnaround, team and
category comparisons, and rejection investigation.

## Resume-Ready Bullets

- Built a normalized PostgreSQL claims operations model with six tables,
  effective-dated SLA rules, Power BI star-schema views, and automated integrity
  checks for a 50,000-claim synthetic dataset.
- Developed Python and SQL KPI pipelines for approval, rejection, turnaround,
  backlog aging, stage SLA, team, category, and rejection analyses, reconciling
  completed-stage SLA at 33.85% and overall-stage SLA at 36.60%.
- Designed a three-page Power BI report covering Executive Overview, SLA &
  Bottlenecks, and Rejection Investigation with separate claim- and event-level
  measures to prevent fan-out errors.
- Added PostgreSQL integration, data validation, Power BI fallback validation,
  and Ruff checks; the verified automated suite passes 16 tests.

## Positioning

This is an independent portfolio project using synthetic data. It demonstrates
data modeling, metric definition, reconciliation, operational analysis, and
dashboard delivery. It does not claim production insurer experience, causal
findings, regulatory compliance, or financial savings.
